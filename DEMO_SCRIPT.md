# 60–90 second demo walkthrough

**Important:** capture the live local model for the open-AI proof. The sample preview is useful for showing the UI but is not evidence of model inference.

1. **Opening (5 sec):** “FramePilot turns a vague client brief into a scoped freelance project pack. It’s for independent video creators who need to handle the business side of making videos.”
2. **Show the input (10 sec):** Use the prefilled cafe winter-menu brief. Point out shoot hours, edit hours, hourly rate and fixed costs.
3. **Generate live (20 sec):** Click **Build my project pack**. Show the local AI status and mention that Gemma is running through Ollama on the machine.
4. **Show the offer/pricing (15 sec):** Open **Offer & pricing**. Explain that package deliverables are model-generated, while price anchors use a transparent formula from the creator’s own numbers.
5. **Show production plan (10 sec):** Open **Production plan** and tick a checklist item. Mention hand-offs and revision guardrails.
6. **Show the client pitch + export (10 sec):** Open **Client pitch**, copy the pitch, then export the Markdown project pack.
7. **Close (5 sec):** “No paid AI API, no default cloud processing, and you can adapt the model and prompts for your workflow.”

Avoid recording private client details or API credentials. If the live model doesn't respond, disclose that and use the preview only as a UI tour—not as a live AI demo.
